FindPlants

FindPlants is a web application that allows users to search for plants and view their locations on an interactive map.
It was built as part of a learning project focused on Python, Flask, and core web development concepts.

Features:

-Search for plants by name or keywords

-View detailed plant information

-Display plant locations using Google Maps

-User login and ability to save favorite plants

-Responsive design for mobile and desktop

-Technologies Used

-Python (Flask)

-HTML, CSS, Bootstrap

-SQLAlchemy

-Google Maps API

This project currently includes a small demo dataset with only a few plants.
Additional plants and locations can be added in the future.
